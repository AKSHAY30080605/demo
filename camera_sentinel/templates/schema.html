Canonical Feature Schema v1 · derived from IoT-SFC conn records

Local camera traffic must map to these features with matching meaning, direction, units and window — not just column names. Missing fields are dropped from both sides, never invented.

Excluded (leakage / identifiers)

Ground-truth and post-event fields (attack, type_of_attack, label_source, attacker_role) and identifiers (uid, window_id, ts, IPs) are never model inputs.
